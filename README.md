# Student Performance Management & Predictive Analytics System

A web-based student performance management system developed using Python, Flask, MySQL and Machine Learning.

## Features

- Student Management
- Subject Management
- Marks Management
- Attendance Management
- Student Performance Analysis
- Data Analysis using Pandas
- Data Visualization
- Interactive Dashboard
- Machine Learning based PASS/FAIL Prediction
- MySQL Database Integration
- CRUD Operations
- SQL JOIN Queries
- Input Validation

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- Pandas
- Scikit-learn
- Matplotlib
- Chart.js
- Git & GitHub
